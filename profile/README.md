This is **PaddleHQ-Forks** — forks of public open-source projects we use at Paddle. Looking for first-party Paddle code, SDKs, or our OpenAPI spec? You probably want [PaddleHQ](https://github.com/PaddleHQ) instead.

## We 💛 open source

Like most companies, we use open source software every day at Paddle. Open source helps us ship great products for our customers, as well as making our working lives more enjoyable. We're grateful to the open source community and look to contribute back where we can — most of the forks here exist as a staging area for changes we plan to send upstream.

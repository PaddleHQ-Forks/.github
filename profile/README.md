This is **PaddleHQ-Forks** — forks of public open-source projects we use at Paddle. Looking for first-party Paddle code, SDKs, or our OpenAPI spec? You probably want [PaddleHQ](https://github.com/PaddleHQ) instead.

## Why this org exists

Forks of third-party OSS sit a little differently to first-party code — they track upstream's conventions, and we want our changes to be easy to send back. Hosting them here, separate from our own code in [PaddleHQ](https://github.com/PaddleHQ), keeps things tidy on both sides.

## What lives here

Each repo here is a **tracking fork** of an upstream public OSS project — the fork relationship points back to the upstream repo on GitHub, and our intent is to send our changes home.

If we've effectively adopted a project (upstream is dormant, or our version has diverged so far that we have no realistic plan to merge back), it lives in [PaddleHQ](https://github.com/PaddleHQ) instead. This org is *only* for forks we still intend to contribute back to.

## We 💛 open source

Like most companies, we use open source software every day at Paddle. Open source helps us ship great products for our customers, as well as making our working lives more enjoyable. We're grateful to the open source community and look to contribute back where we can.
